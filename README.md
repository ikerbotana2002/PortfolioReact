# Portfolio Personal - Iker Botana Vázquez

Portfolio web personal desarrollado con React, mostrando información personal, educación, experiencia, habilidades y proyectos tanto académicos como personales.

## 🚀 Características

- **Diseño Moderno**: Interfaz moderna y atractiva con animaciones suaves
- **Responsive**: Completamente adaptable a diferentes dispositivos
- **Secciones Completas**:
  - Sobre Mí
  - Educación
  - Experiencia
  - Habilidades
  - Proyectos (con filtros por categoría)
  - Contacto

## 🛠️ Tecnologías Utilizadas

- React 18.2.0
- React Icons
- CSS3 con animaciones
- Diseño responsive

## 📦 Instalación

1. Clona el repositorio o descarga los archivos
2. Instala las dependencias:

```bash
npm install
```

3. Inicia el servidor de desarrollo:

```bash
npm start
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador

## 📝 Personalización

Puedes personalizar el contenido editando los componentes en `src/components/`:

- **About.js**: Información personal y biografía
- **Education.js**: Datos de educación
- **Experience.js**: Experiencia laboral/profesional
- **Skills.js**: Habilidades técnicas
- **Projects.js**: Proyectos personales y académicos
- **Contact.js**: Información de contacto

## 🎨 Personalización de Estilos

Los estilos están organizados en archivos CSS individuales para cada componente. Puedes modificar los colores, fuentes y animaciones en los archivos `.css` correspondientes.
