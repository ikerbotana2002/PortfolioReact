# Portfolio Personal - Iker Botana Vázquez

Portfolio web personal desarrollado con React, con despliegue automático mediante Vercel (CI/CD).

🌐 **Web:** https://ikerbotana.com

## 🚀 Características

- Diseño responsive para escritorio, tablet y móvil
- Navegación por diferentes secciones del portfolio
- Animaciones e interacciones mediante CSS
- Filtrado de proyectos por categoría
- Sección de contacto
- Enlaces a GitHub y LinkedIn

## 🛠️ Tecnologías

- React 18
- JavaScript
- HTML5
- CSS3
- React Icons
